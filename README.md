# Finorizon

**Personal Financial Planning & Forecasting**

Plan your financial goals, explore alternative scenarios, and understand how today's financial decisions may affect your future.

## Project Status

Currently in development.

## Core Features

- Income and expense management
- Savings goal planning
- Financial forecasting for 12–60 months
- What-if scenario analysis
- Comparison of alternative scenarios

## Technology Stack

Planned: Next.js, TypeScript, Tailwind CSS, Supabase, PostgreSQL, and Recharts.

## Project Scope

The initial version focuses on reliable, transparent financial calculations and scenario comparisons. AI chat and real bank integrations are outside the initial MVP scope.
